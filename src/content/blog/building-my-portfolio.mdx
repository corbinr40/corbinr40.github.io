<div className="section-wrapper">
  <FeatureSection title="The Stack">
    <p>This portfolio is built with <b>React 19</b>, <b>TypeScript</b>, and <b>Bootstrap 5</b>, bundled with <b>Vite</b>. Content is written in <b>MDX</b> (Markdown with JSX), which lets me embed React components directly in my writing.</p>
    <p>The site is hosted on <b>GitHub Pages</b> and deployed automatically via GitHub Actions whenever I push to the main branch.</p>
  </FeatureSection>
</div>

<div className="section-wrapper">
  <FeatureSection title="The Content System">
    <p>Instead of hardcoding each project page as a separate React component, I built an MDX-based content system. Each project or blog post is a single <code>.mdx</code> file with YAML frontmatter for metadata and MDX for the content body.</p>
    <p>Adding a new project means creating one file - no routing changes, no data file edits. The content registry auto-discovers all MDX files at build time using Vite's <code>import.meta.glob</code>.</p>
    <ul>
      <li>10 block types: Hero, Overview Table, Feature Section, Image Carousel, Image+Paragraph, Code Block, Video Embed, Callout, Quote</li>
      <li>Automatic project card generation from frontmatter</li>
      <li>Dynamic routing - one route handles all content pages</li>
    </ul>
  </FeatureSection>
</div>

<div className="section-wrapper">
  <FeatureSection title="The Editor">
    <p>To make content creation even easier, I built a full GUI editor at <code>/editor</code>. It's a block-based editor (similar to Notion or WordPress Gutenberg) where you can:</p>
    <ul>
      <li>Fill out project metadata through a form</li>
      <li>Add and reorder content blocks with drag-and-drop</li>
      <li>Write rich text with a toolbar (bold, italic, links, lists)</li>
      <li>Upload images with drag-and-drop</li>
      <li>Preview content live using the actual site components</li>
      <li>Save drafts locally and export as MDX or ZIP</li>
      <li>Publish directly to GitHub via the API</li>
    </ul>
    <p>The editor is lazy-loaded and hidden from search engines, so it doesn't affect the site's performance or SEO for visitors.</p>
  </FeatureSection>
</div>
